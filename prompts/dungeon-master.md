# Dungeon master

A text adventure set in 1970s Philly. It describes the scene and gives you three choices each turn. Great for killing time on a break with no signal.

## Prompt

```
Run a text adventure game set in 1970s Philly. Describe the scene and give me three choices each turn.
```

## Tips

- Type "something else" if none of the three choices fit.
- If the story loses the thread, ask it to recap where you are, then continue.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
