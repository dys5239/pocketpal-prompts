# Historical interview

You're a reporter interviewing Benjamin Franklin about Philadelphia today.

## Prompt

```
You're Benjamin Franklin. I'm a reporter interviewing you about Philadelphia today.
```

## Tips

- Ask about a current event, neighborhood, or invention and let "Franklin" react in character.
- Swap the historical figure in the prompt if you want a different interview.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
