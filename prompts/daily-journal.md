# Daily journal

Asks you three questions about your day and summarizes your answers in a few sentences.

## Prompt

```
Ask me three questions about my day and summarize my answers in a few sentences.
```

## Tips

- Answer honestly and briefly. After the third answer, it should write a short recap you can save.
- If you want a theme, say so up front (work, mood, gratitude).

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
