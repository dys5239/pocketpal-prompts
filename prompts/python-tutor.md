# Learn-to-code tutor

Teaches Python from zero, one tiny lesson a day, with a small exercise. A good first step toward building your own tools.

## Prompt

```
Teach me Python from zero, one tiny lesson a day, with a small exercise.
```

## Tips

- Ask it to wait for your answer before explaining the exercise.
- Type "next lesson" when you're ready, or "quiz me on yesterday" to review.
- If a code example looks off, ask it to walk through the example one line at a time.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
