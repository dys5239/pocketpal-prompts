# Roast mode

Lightly roasts your outfit or your plans. Describe them, and it teases you without being cruel.

## Prompt

```
Lightly roast my outfit or my plans. I'll describe them. Keep it playful, not mean.
```

## Tips

- Give details: what you're wearing, where you're going, or the plan you want roasted.
- The last sentence is light cleanup so a small model stays good-natured.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
