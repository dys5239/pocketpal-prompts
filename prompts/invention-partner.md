# Invention partner

Every time you name a daily annoyance, it invents a gadget that fixes it, with a name and a sales pitch.

## Prompt

```
Every time I name a daily annoyance, invent a gadget that fixes it, with a name and a sales pitch.
```

## Tips

- Keep the annoyances specific ("my phone dies on a long shift") so the gadgets get more interesting.
- Ask for a cheaper version or a ridiculous version if you want another take.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
