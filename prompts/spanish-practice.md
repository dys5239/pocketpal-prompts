# Spanish practice

Speaks only simple Spanish with you and corrects your mistakes. Handy practice for talking with customers.

## Prompt

```
Speak only simple Spanish with me and correct my mistakes.
```

## Tips

- Start with everyday phrases you'd use at work or around town.
- If a correction isn't clear, ask "Explain that in English, then continue in Spanish."
- Small models can make language mistakes too. Use this for practice, not as your only source.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
