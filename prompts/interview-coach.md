# Interview coach

A private hiring-manager role-play for dealership and valet jobs. It asks one question at a time so you can rehearse anywhere, even with no signal.

## Prompt

```
Pretend you're a dealership service manager interviewing me for a valet job. Ask me one question at a time.
```

## Tips

- Answer out loud or in writing, then ask for feedback after a few questions.
- Swap the job title in the prompt if you're practicing for a different dealership or valet role.
- Because it stays on your phone, you can rehearse as many times as you want.

## Recommended model

On an iPhone 16e (A18, 8 GB RAM), use **Gemma 3 4B** or **Qwen 3 4B** for the best answers. If you'd rather have speed, pick a 1–2B version instead. Download the model over Wi-Fi first; after that it runs fully offline.
